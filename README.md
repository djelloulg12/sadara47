# منصة النادي الرياضي الصدارة

منصة عربية RTL لفوج السباحة، بواجهة إدارة وخادم API وقاعدة SQLite محلية.

## التشغيل المباشر

شغّل الخادم المحلي:

```bash
npm start
```

ثم افتح العنوان الذي يظهر في الطرفية. ينشئ الخادم تلقائيًا ملف `sadara.db`. لإنشاء حسابات الإدارة في بيئة جديدة، عرّف البريد وكلمة المرور عبر متغيرات البيئة `SADARA_ADMIN_EMAIL` و`SADARA_ADMIN_PASSWORD`، مع المتغيرات المناظرة للرئيس والمدرب.

رئيس الجمعية يستطيع من لوحة التحكم مراجعة الطلبات، اعتمادها، وتغيير الخطة والخدمات الإضافية؛ يعاد احتساب المبلغ تلقائيًا ويسجل القرار في سجل المراجعة.

## ما تم ربطه فعليًا

المصادقة الحقيقية بجلسة خادم، قاعدة SQLite، السباحون، الإعلانات، البرنامج الأسبوعي، الحضور والبطاقات. ملفات `schema.sql` و`server.py` هي نقطة التوسعة لتعدد المستخدمين والصلاحيات.

## النشر

شغّل `python server.py` على خادم يدعم Python، ثم ضع Reverse Proxy مع HTTPS. لا ترفع `sadara.db` إلى مستودع عام.

## تحويلها إلى نسخة إنتاجية

للنشر العام، يُنصح بنقل الجداول نفسها إلى PostgreSQL، تغيير كلمة مرور الإدارة، وإضافة بريد/استرجاع كلمة المرور ورفع الصور. لا تستخدم بيانات الدخول التجريبية في الإنتاج.
